# Strands Agents `toolUse` Input Validation Demo

This repository demonstrates an input validation flaw that lets a caller execute a Strands tool by submitting forged `toolUse` input, without the model deciding to call the tool, and three input checks that prevent it.

The same examples are available in two languages. They differ only in the system prompt, the inputs, and the error messages.

- [English](en/README.md)
- [日本語](ja/README.md)
